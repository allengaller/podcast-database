## 总结(据公开报道整理)

**一句话主旨**:具身智能(embodied AI)正处在"端到端黑盒大模型"与"上下分层(感知-决策分层)"的路径分野关键期——苏度科技韩铮提出"暴论":2026 下半年"上下分层"将重回硅谷机器人主流,与 Figure / Tesla Optimus / Physical Intelligence 押注的端到端路线正面交锋。

**核心论点(≤3)**:
1. **3D 数据是物理世界机器人的真正瓶颈**:与"在虚拟世界里控制运动"相比,"在真实世界操作物体"的难度提升 2-3 个数量级——动手前必须先理解眼前物理世界
2. **路径分野:端到端 vs 上下分层**:
   - **端到端**(Figure / Tesla / PI):沿用 LLM 范式,黑盒大模型直接输出动作
   - **上下分层**(苏度主张):感知与决策解耦,3D 几何 / 物理建模独立栈
3. **"大脑和本体都做"的全栈主张**:韩铮团队 10 年前就开始用机器学习方法驱动机器人,坚持"全栈系统"——既是能力来源,也是商业护城河

**关键事实 / 数据**(精听后补注出处):
- 苏度科技定位"大脑和本体都做",团队规模 / 融资轮次 TODO
- 硅谷主流(Follow Tesla / Figure / PI)押注"端到端大模型"路线,2026 上半年是默认共识
- 韩铮的"暴论":"从今年下半年开始,'上下分层'重回硅谷主流"(YouTube Shorts 7 月发布)
- 节目副标题:"3D 数据、路径分野与硅谷竞赛"——三关键词分别对应:数据瓶颈 / 路径分歧 / 产业格局

**嘉宾立场**:
- 韩铮(苏度科技):**上下分层派**,代表"反对端到端黑盒"的工程派立场
- 苏度(创始人):**全栈派**,主张"大脑 + 本体"都自研,避免被任何单层供应商卡脖子

## 分析

**为什么本集值得精读**:
1. **具身智能的"路径之争"才刚开始**:2025 年 Figure 02 / Tesla Optimus Gen 2 / PI-0 让端到端路线成为主流叙事,但本集把"另一条路"摆到台面
2. **3D 数据问题是大模型范式的真正短板**:LLM 在文本上能用 scaling law 暴力解决,但物理世界的"长尾+连续性"让暴力路线成本过高——本集为这条行业疑虑提供了工程派回应
3. **中国具身智能的视角**:苏度科技是中文世界具身智能头部,本集是少有的"中文世界 vs 硅谷主流"直接对话

## 洞察

**可复用的框架**:
- **端到端 vs 上下分层**二分法:在自动驾驶、机器人、agent 等所有"物理 / 决策"领域都适用
- **"数据维度"瓶颈曲线**:1D 文本 → 2D 图像 → 3D 几何 → 物理仿真,每一维度数据成本陡升
- **"全栈 vs 单层"商业选择**:全栈是能力与护城河,也是研发负担;单层灵活但有被卡脖子风险

**对本研究语料库的方法论意义**:
- 本集是"路径之争"主题的标准报道样本:不偏袒某一方,把"暴论"摆出来让听众判断
