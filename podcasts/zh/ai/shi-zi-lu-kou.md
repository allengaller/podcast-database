# 十字路口 Crossing

## 简介

《十字路口》是一档由新世相 / 躺岛联合创始人杨远骋 Koji 与前《第一财经周刊》驻硅谷记者 Ronghui 联合主理的中文科技 / 商业 / 创业播客,2024 年上线,2025 年获小宇宙「年度新播客」+「年度趋势播客(前沿科技)」双项大奖。节目名取自乔布斯对苹果公司的经典比喻——"站在科技与人文的十字路口,伟大的产品往往诞生在这里",Koji 把它延伸为:"AI 正在给各行各业带来改变,我们寻找、访谈和凝聚 AI 时代的「积极行动者」,和他们一起,探索和拥抱新变化,新的可能性。"

节目核心形态是 60–120 分钟的深度对谈 + 圆桌沙龙 + 「20 问」结构化专栏。嘉宾覆盖中文世界 AI 创业 / 大模型 / 机器人 / 具身智能 / 芯片 / 投资 / 互联网 / 商业 / 历史的代表性人物,2024–2026 年嘉宾名单包括:袁进辉(硅基流动创始人)、idoubi(ThinkAny / 独立开发者头部)、猫助(多抓鱼创始人)、袁菁(沐瞳科技联合创始人,40 亿美金被字节收购)、谢扬(Authing / Fellou 创始人)、冯骥(游戏科学创始人,《黑神话:悟空》)、李乐丁(DeepSeek 20 问特别篇)、MiniMax、Perplexity、Luma AI、Sand.ai 创始团队等。2025 年起在上海漕河泾开发区联合硅谷社群 Aligns AI 共同发起 AI Hacker House(300 平湖边独立小楼),定期举办行业沙龙、黑客松与「加速器」预孵化。

## 主理人背景

- **杨远骋 Koji**:新世相 / 躺岛联合创始人,长期关注 AI 与新内容范式的交叉。Koji 强调"我们更看重产品,而不只是技术",代表新世相系科技 / 文化 / 商业融合视角;同时是十字路口 AI Hacker House 的主要发起人,代表中文 AI 创业者社群的运营型代表。
- **Ronghui**:科技 VC,前《第一财经周刊》驻硅谷记者,长期跟踪中美科技 / 创业 / 投资议题;负责十字路口的"硅谷视角"和"VC 视角",与 Koji 形成"产品 / 文化 + 资本 / 战略"互补。

节目得到「新世相声音森林播客计划」支持,2025 年会员群包括"第一手 AI 资讯 + 鼓励大家谈恋爱/交朋友/寻找未来的同路人"等社区运营模块,代表中文 AI 创业社群的"内容 + 社区 + 线下空间"复合形态。

## 内容定位与形式

- **核心模块**:
  1. **深度对谈**:60–120 分钟嘉宾访谈,选题覆盖大模型 / 具身智能 / 独立开发 / SaaS / 出海 / 机器人 / 商业 / 投资 / 历史 / 哲学;
  2. **「20 问」专栏**:针对重大技术 / 商业事件的"结构化思考框架",2025-02 推出首期《20 个问题,搞懂 DeepSeek 和它带来的"AI 下半场"》,邀请前百度主任高级架构师 / 十字路口老朋友李乐丁;
  3. **行业沙龙**:2025-03-22 《后 DeepSeek 时代的十字路口,2025 AI 创投新机遇》在上海 AI Hacker House 举办,高瓴创投合伙人王蓓 Betty + 真格基金合伙人刘元 + Youmind 创始人玉伯 + 米粿 AI 创始人丁黎 + 海豚浏览器创始人杨永智(盛智);
  4. **AI Hacker House**:与硅谷社群 Aligns AI 联合,2025 年起在上海漕河泾开发区运营 300 平湖边独立空间,周围环绕字节、腾讯、商汤、米哈游、美光、ARM 等 500+ AI 企业;与 Demo Inn、Let's Vision、SH Hacks 等社群联合举办行业活动;Spark Lab 驻地团队正在筹备"加速器"项目;
  5. **会员群**:「AI 新鲜事小报」+「跨行业社交」+「找同路人」社区模块;
  6. **跨节目联动**:与「硬地骇客」「商业漫谈」(卫诗婕)等节目串台 / 联动,代表中文 AI 创业社群的横向连接。
- **代表选题方向**:
  - **大模型战略**:袁进辉 + idoubi《AI 工程师指南:我是谁,从哪来,到哪去?》(2024)、李乐丁《20 个问题,搞懂 DeepSeek 和它带来的"AI 下半场"》(2025-02);
  - **AI 应用与独立开发**:Saito + 硬地骇客《从焦虑到自由:AI 时代每个人如何拥有自己的小生意?》(EP64,2024-06-17);
  - **具身智能 / 机器人**:沐瞳科技袁菁《40 亿美金卖掉公司后,一个创业者的过去、现在和未来规划》(2025-02)、Fellou 谢扬《34.与 Fellou 创始人谢扬的 3 小时访谈:孤独、95 后、牌桌与生产力的完美创业》(2025-04);
  - **AI 时代的人生选择**:多抓鱼猫助《一个不太焦虑的 CEO 是怎么练成的》(2025-03-30);
  - **AI 与创作**:游戏科学冯骥《黑神话:悟空》对行业的影响(EP 多次涉及);
  - **AI 与海外 / 全球化**:Luma AI 产品经理 Barkley、Sand.ai 创始人曹越的访谈;
  - **AI 与商业**:MiniMax 等头部 AI 公司的 PM 视角访谈。

## 受众画像

- **中文 AI 创业者 / 准创业者**:把节目作为"中文 AI 创业社群"的主入口,关注 AI 应用 / 独立开发 / 投资 / 出海 / 创业机会;
- **科技 VC / 早期投资人**:从节目跟踪 AI 赛道最新动态、嘉宾质量、行业判断;
- **大厂产品 / 技术管理者**:寻找"AI 时代转型"和"超级个体"路径;
- **独立开发者 / 自由职业者**:从节目学习"AI 时代如何做产品、搞营销、找 PMF";
- **AI 时代焦虑的年轻人**:节目多次正面回应"听十字路口会焦虑"的反馈,代表"AI 时代也可以不焦虑"的中文声音;
- **新世相 / 躺岛系读者**:跨文化 / 跨消费的"新世相读者"圈层。

## 影响力与评测

- **平台数据**:小宇宙订阅 + 微信公众号 + 微博多渠道分发,2025 年获小宇宙「年度新播客」+「年度趋势播客(前沿科技)」双项大奖;
- **AI Hacker House**:与硅谷 Aligns AI 联合运营,2025 年起在上海漕河泾运营 300 平湖边独立空间,周边 500+ AI 企业(字节 / 腾讯 / 商汤 / 米哈游 / 美光 / ARM),代表中文 AI 创业社群实体化运营的代表项目;
- **2025 行业沙龙**:2025-03-22《后 DeepSeek 时代的十字路口,2025 AI 创投新机遇》近 100 位朋友到场,300+ 报名;
- **行业引用**:与「硬地骇客」「商业漫谈」「纵横四海」等头部中文播客深度联动,被第一财经、虎嗅、晚点 LatePost、36 氪、知乎等媒体二次引用;
- **代表中国 AI 时代的"内容 + 社区 + 线下空间"复合范式**:与传统的"播客 + 听众"模型不同,十字路口通过会员群 + AI Hacker House + 加速器预孵化,形成了"中文 AI 创业者社群"的实体运营。
