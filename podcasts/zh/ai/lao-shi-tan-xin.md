# 老石谈芯

## 简介

《老石谈芯》是一档聚焦半导体、芯片与 AI 算力基础设施的中文科技播客/视频节目,由"老石"主理,内容以"硬核芯片科普 + 高密度大咖访谈"为主轴。节目名中的"老石"取自中科院副研究员、帝国理工博士的网名,本人长期在芯片设计、FPGA、RISC-V、AI 加速器等方向做研究与科普,既是一线科研者,也是头部芯片科普创作者。

节目以"芯片科普"为根,向"AI 时代算力"延伸,选题覆盖 GPU / NPU / FPGA / ASIC、芯片代工与设备、AMD / NVIDIA / Intel / 联发科 / 阿里平头哥 / 开芯院等公司的产品与战略,以及 AI 算力对数据中心、自动驾驶、机器人、消费电子的拉动。子栏目"大咖谈芯"以深度访谈为主,代表嘉宾包括安克创新 CEO 阳萌、阿里达摩院首席科学家、AMD 高管 Jack Huynh、联发科技术负责人等。

节目 2018 年前后在 bilibili 起家,目前已成长为中文芯片科普的头部 IP 之一,与"差评君""影视飓风""硬核的半佛仙人"等并列为代表性科技自媒体。

## 主播与背景

- **老石**:中科院副研究员 / 帝国理工电子系博士,前 Intel 芯片工程师(自述),长期从事芯片设计、FPGA 加速、AI 加速器等方向研究,论文发表于 MICRO、ASPLOS、FPGA 等国际顶级会议与期刊,获 IEEE Micro Top-Picks 论文奖、两次 HiPEAC 论文奖。是国内 FPGA 与 RISC-V 方向最知名的科普作者之一。

老石的科普风格被业内概括为"能讲清楚芯片设计底层逻辑"——既能拆解 CPU 流水线、存算一体架构、FPGA 异构计算等硬核技术,也能把它们翻译成产业人看得懂的产品语言。这使得节目在芯片从业者、电子/计算机专业学生、硬科技投资人、AI 算力相关产品经理中都有稳定受众。

## 内容定位与形式

- **两档核心节目形态**:
  1. **《老石谈芯》主节目**:硬核芯片科普 + 行业新闻速递,选题包括 AMD/NVIDIA/Intel/Apple M 系列芯片新品、ASPLOS/MICRO/FPGA 顶会论文、芯片代工与设备产业事件;
  2. **《大咖谈芯》**:深度访谈系列,嘉宾多为芯片与硬科技公司创始人、CEO、技术负责人,单期 30–60 分钟,代表访谈包括安克创新 CEO 阳萌(2024,存算一体芯片与大模型时代的存储挑战)、阿里达摩院首席科学家(2024,玄铁 C950 与 RISC-V 开芯生态)、AMD 高级副总裁 Jack Huynh(AMD AI 战略)等。
- **常驻子栏目**:
  - **「全球芯闻」**:周一到周五早七点半发布的"全球大小芯闻"日报,覆盖 IP / 制造 / 设备 / 设计的全产业链新闻;
  - **深度专题**:对单一芯片产品/技术做 30–60 分钟深度拆解,如 NVIDIA Blackwell、苹果 M5、Vera Rubin 超级计算机、Intel Crescent Island 等。
- **更新节奏**:bilibili 视频周更 2–4 期,头条与微博同步分发,常在芯片新品发布、顶会前后做加更。

## 受众画像

- **芯片与硬件工程师**:作为对国内外芯片设计、流片、验证、FPGA、AI 加速等方向的"听得懂 + 看得到"的科普;
- **AI 算力相关从业者**:数据中心 / 大模型 / 推理芯片 / GPU 替代方向的产品 / 技术 / 战略;
- **硬科技投资人**:理解芯片产业动向、评估被投项目的技术与团队;
- **电子与计算机专业学生**:补充"课本外"的产业视角与一线研究动态;
- **科技爱好者**:偏好"硬核但讲人话"的硬科技内容。
