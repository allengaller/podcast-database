# What's Next | 科技早知道(原「硅谷早知道」)

## 简介

《What's Next | 科技早知道》原名《硅谷早知道》,是一档由资深商业科技记者徐涛主理的中文播客,2016 年在 Apple Podcasts 上线,2019 年徐涛成立声动活泼(上海斛律网络科技有限公司)后成为声动活泼的旗舰节目。节目定位"放眼全球,聚焦科技,关注科技引领世界以及商业格局变化",后于近年全新改版为「What's Next|科技早知道」,在保留科技主线的同时加入了"出海"、"商业格局变化"等新模块。

节目节奏以"周五中午"固定更新为标志(原硅谷早知道),每期 30–90 分钟,围绕"一家硅谷公司 / 一项前沿技术 / 一件产业大事"做深度报道 + 评论。嘉宾包括《TechBuzz China》主理人马睿(TechBuzz China / 哈佛心理学硕士)、Y Combinator 系创业者、Stanford / Berkeley 教授、华人创业者、以及被声动活泼的报道触达的中国出海团队等。

2026 年初口径,《What's Next | 科技早知道》在懒人听书累计更新 283 期、11.98G、223 小时,被业内视为中文世界"硅谷视角科技报道"的开创性节目之一。

## 主播与背景

- **徐涛**:声动活泼创始人 / 制作人,早年任第一财经记者 / 36 氪驻硅谷负责人,2016 年开始尝试做播客,在 Apple Podcasts 上线《声东击西》《硅谷早知道》;2019 年成立声动活泼(对标 NPR 的内容矩阵),同年获光涧实验室投资。代表方法论:"先做内容很好的 Podcast,再扩成公司",对标 NPR 美国广播网。
- **丁教**:联合主播 / 制作人,与徐涛共同负责节目选题、剪辑与发布;丁教也在声动活泼的多档节目(《声东击西》《反潮流俱乐部》《What's Next | 科技早知道》等)中担任制作人。

声动活泼旗下的内容矩阵还包括《声东击西》(记者视角的世界新闻解读)、《声动早咖啡》(商业科技轻解读 15 分钟早间节目)、《组织进化论》(字节跳动飞书联合出品,职场 / 组织话题)、《跳进兔子洞》(叙事类调查播客)、《What's Next | 科技早知道》等。

## 内容定位与形式

- **核心模块**(改版后):
  1. **科技深度报道**:前沿技术(AI / 芯片 / 量子 / 生命科学 / Web3 等)+ 硅谷大厂动态;
  2. **出海视角**:中国科技 / 消费 / 跨境电商 / 软件出海公司的全球化故事;
  3. **多视角解读**:对科技行业大事件做多嘉宾 / 多角度的拆解(类似 Lex Fridman 的"长访谈"+ Hard Fork 的"新闻速评"混合);
  4. **行业人物**:华人 / 中美两栖科技从业者的访谈。
- **典型结构**:30–60 分钟"主话题" + 5–10 分钟"次话题速评" + 5 分钟"轻推荐";
- **更新节奏**:改版后继续维持周五更新,但在重要事件(模型发布、行业大会、IPO 等)前后会做加更;
- **代表选题**:
  - **2018–2020(硅谷早知道时期)**:Facebook 工作压力 / 硅谷职场 / Quibi 好莱坞挑战奈飞 / 印度疫情 / 互联网出海;
  - **2019**:与马睿、Garry 合办"逃避、冥想、看心理医生"线下特别版;
  - **2024–2026(What's Next 时期)**:AI 大模型公司战略 / 开源生态 / 算力供应链 / 端侧 AI / 具身智能 / 出海应用层。

## 受众画像

- **中文世界的科技 / 互联网 / 投资从业者**:把节目作为"硅谷视角中文转述"的一手信号源;
- **出海创业者**:通过节目跟踪海外市场动态、竞争格局、政策与文化;
- **AI 创业者 / 投资人**:对 OpenAI / Anthropic / Google DeepMind / Meta AI / NVIDIA / Apple 等公司战略的判断;
- **科技爱好者**:偏好"周五中午固定更新"的稳定节奏与"记者 + 制作人"的专业产出;
- **企业战略 / 品牌 / 营销人士**:从节目对全球趋势的判断中获取决策输入。

- **行业地位**:中文"硅谷视角科技播客"的开创节目,声动活泼旗舰 IP,与《日谈公园》《大内密谈》《Just Pod 系(忽左忽右 / 东亚观察局 / 杯弓舌瘾)》并列第一梯队;

- **公司层面**:声动活泼 2019 年获光涧实验室投资,后 TME 投资上海斛律网络科技,形成《声东击西》《硅谷早知道 / What's Next》《声动早咖啡》《跳进兔子洞》《组织进化论》矩阵,代表"中文严肃音频媒体"的标准范式;
