# 半拿铁 | 商业沉浮录

## 简介

《半拿铁 | 商业沉浮录》是一档以"用说相声的方式讲商业故事"为定位的中文播客,由刘飞(@刘飞Lufy)与老同学潇磊联合主理,2022 年 3 月正式上线。节目名取自"半拿铁"咖啡——既要纯粹又要稀释,寓意节目希望用轻松、接地气的方式,讲述那些原本"遥不可及"的商界大拿的真实故事。

节目核心形态是 60–180 分钟的"商业故事专辑",每期围绕一位商业人物 / 一家代表公司做深度拆解,从个人经历与生活环境寻找"成事动机",辅以插科打诨与"埋钩子"等相声手法控制听众留存。截至 2026 年 6 月,网易云音乐显示已更新 229 期(口径),代表作包括《中国互联网故事》连续系列(从史前科技巨头四通到 2025 年的盛大和阿里)、《中国汽车史》系列(从合资车到比亚迪 / 吉利 / 蔚来 / 理想)、《洋品牌史》系列(肯德基 / 星巴克 / 麦当劳 / 福特等)、《饮食男女》系列(中国餐饮品类专题)、《三体》番外、《节假日史》系列(春节 / 中秋等)等。

2023 年,《半拿铁》登顶喜马拉雅"2023 中文商业评论播客排行榜",并成为中文播客领域年度增长最快的播客之一。节目也获 2023 年 CPA 中文播客超频奖(与永璞咖啡合作)。

## 主播与背景

- **刘飞(@刘飞Lufy)**:主理人,前互联网大厂产品经理,大厂产品经理 / 播客主 / 创业者"斜杠青年"。大学时是相声社社长(后因搭档问题转与潇磊合作),有产品经理的"找差异化"思维,擅长把商业内容的"输出专业知识"转向"有叙述性的商业故事"。
- **潇磊**:刘飞的大学老同学,在传媒系统内做财经口内容,喜欢播客,与刘飞同在杭州,2022 年被刘飞拉来搭档《半拿铁》,二人以"老同学 + 老搭档"为核心创作单位,延续大学时的相声底子。

刘飞同时还主理另一档播客《三五环》("三环进不去、五环出不去"的中年自嘲),定位是科技 / 互联网 / 产品的对谈。两条节目在制作团队、嘉宾资源、商业化打法上深度协同。

## 内容定位与形式

- **核心形式**:60–180 分钟的长篇商业故事专辑,常以系列形式呈现(每系列 4–10 期,讲透一个赛道或一家公司);
- **典型结构**:从"个人经历 / 生活环境"切入,而不是从"成果"切入;用"插科打诨"和"埋钩子"控制节奏;每期有 shownotes 详细时间轴与资料;
- **常驻系列**:
  - **《中国互联网故事》**:史前科技巨头四通 → 网易 → 搜狐 → 新浪/微博 → 百度 → 腾讯 → 阿里 → 美团 → 字节 → 拼多多 → 京东 → 滴滴,目前更新到 21 期(2026 年 6 月口径);
  - **《中国汽车史》**:从合资车(上海大众 / 富康 / 夏利)→ 自主品牌(吉利 / 比亚迪 / 蔚来 / 理想)→ 行业政策;
  - **《洋品牌史》**:肯德基 / 麦当劳 / 星巴克 / 福特 / 欧莱雅 / 博世等;
  - **《饮食男女》**:中国餐饮品类专题(火锅 / 烧烤 / 面条 / 速食等);
  - **《节假日史》**:春节 / 中秋 / 端午等;
  - **《三体》番外**:把《三体》当商业寓言来解读;
  - **《2024 / 2025 年终企划「震楼机」」**:年度财经新闻盘点;
  - **番外**:与李诞、毛冬、高樟资本范卫峰等串台。
- **更新节奏**:周更 + 番外穿插。

## 受众画像

- **一二线城市的上班族 / 学生 / 中基层管理者**(刘飞 2024-01 调研 2019 份问卷结论):女性偏多,90 后占比 50%+,主要收听场景为通勤、家务、睡前、健身;
- **互联网 / 科技 / 商业从业者**:对中文商业故事的"轻量深度"版本有强需求;
- **创业者 / 投资人**:通过商业故事理解赛道和公司战略;
- **播客重度用户**:喜欢 100+ 分钟长内容,完播率(小宇宙)达 71.4%。

## 影响力与评测

- **平台数据**(2024-01 口径,刘飞自述):小宇宙订阅 23.8 万,中文播客订阅第 28 位;小宇宙期均播放 7–9 万、喜马拉雅期均 20 万左右、Apple Podcasts + 网易云合计约 30 万;完播率(小宇宙)71.4%,平均打开率 31%,互动率 0.5%;
- **2023 年喜马拉雅中文商业评论播客排行榜**上榜(与《三五环》同时登榜);
- **2023 年 CPA 中文播客超频奖**(与永璞咖啡合作案例);
- **品牌合作**:迄今 4 次——永璞咖啡 10 期、德国双心 3 期、影石 insta360 4 期、农夫山泉·东方树叶 1 期;2024 春节前保持 2023 价格,年后涨价到 6 位数/期;
- **行业引用**:商业故事选题与节奏设计常被同行(《纵横四海》《声动早咖啡》《疯投圈》《商业就是这样》等)引用借鉴。
