# 道听途说

## 简介

**假艺术节出品的「艺术 / 表演 / 设计」主题播客** —— 主理人 **橘子(Orange Elephant)** 主理,「**假艺术节**」出品,围绕艺术、戏剧、表演、设计、建筑等领域展开对谈与采访。题材覆盖当代艺术家访谈、戏剧评论、设计实践等,代表单期《**Leo Xu:不稳定的系统,令人困惑的时间**》《**Toi Toi Toi #1 | Jan Martens:粉身碎骨,然后呢?**》等。被视为中文「**艺术 / 设计 / 表演**」垂类独立播客的代表样本之一。

## 主理人背景

- **橘子(Orange Elephant)** —— 主理人,具体个人背景以节目页为准;假艺术节核心成员之一。
- **假艺术节(Fake Festival)** —— 中文艺术 / 戏剧 / 表演领域的独立内容平台。

## 内容定位与形式

- **赛道**:艺术 / 戏剧 / 表演 / 设计(本库 zh/tech,因话题涉及设计与艺术科技交叉)
- **形式**:**主理人主持 + 艺术家 / 设计师嘉宾深度对谈**
- **更新频率**:不定期
- **单集时长**:40-90 分钟
- **语言**:中文

## 受众画像

- 中文艺术 / 戏剧 / 设计从业者、艺术爱好者、当代艺术关注者
- 对「**实验性表演 / 设计 / 戏剧**」感兴趣的城市文化群体
