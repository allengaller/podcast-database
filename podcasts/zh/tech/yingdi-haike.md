# 硬地骇客

## 简介

聚焦独立开发(indie hacking)、软件出海与一人 / 小团队创业的中文播客。讨论从 0 到 1 做产品的真实路径、变现、增长与踩坑,是中文 indie hacker 社区的代表性内容之一。

## 主播与背景

- **Macing、Misa、Leon** —— 均为独立开发者 / 出海创业者,各自有在做的产品,讨论来自一手实践。

## 内容定位与形式

- **赛道**:独立开发 / 软件出海 / 小团队创业
- **形式**:多人对谈,常带"这周我做了什么"式实战复盘
- **更新频率**:周更
- **单集时长**:约 60-90 分钟
- **语言**:中文

## 受众画像

独立开发者、想做副业产品或出海软件的程序员 / 设计师、关注 SaaS 与 micro-SaaS 的创业者。

## 代表单集

- 出海产品从 0 到 1 的实战复盘类单集。
- 独立开发者变现与增长策略讨论。

## 影响力与评测

- 中文独立开发 / 出海赛道的头部节目之一,在 indie hacker 圈层影响力显著。
- 商业模式:赞助 + 主播自有产品。
