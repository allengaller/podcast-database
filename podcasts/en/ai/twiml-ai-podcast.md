# The TWIML AI Podcast (formerly This Week in Machine Learning & AI)

## 简介

英文世界**最长寿、累计影响最深的 AI 播客之一**。原名 *This Week in Machine Learning & AI*，由 **Sam Charrington** 主持，2016 年开播至今已积累 600+ 期（**TODO 精确集数**）。每期 1-2 小时深度访谈，嘉宾覆盖**学术界（一线研究者）+ 工业界（CTO / 首席科学家）+ 开源 / 初创（库作者）**三圈。节目定位 **"machine learning / deep learning / NLP / data science 的一线工作流与研究"**——既不是新闻速递，也不是创业访谈，而是"工程师与研究者之间"的那条信息线。

## 主理人与背景

- **Sam Charrington** —— TWIML 创始人，分析师/产品经理出身（前科技公司）。在 AWS 担任分析师期间系统跟踪 ML 平台与企业落地，2016 年独立创办 TWIML。**节目名变更史**：
  - 2016-2022：*This Week in Machine Learning & AI*（TWIML）
  - 2022+：正式简化为 *The TWIML AI Podcast*（缩短名字以适应 LLM 时代"AI" 比 "ML" 更高频使用）
- **TWIML 平台矩阵**：
  - *The TWIML AI Podcast*（主节目）
  - **TWIML Events**（线下大会：TWIMLcon，覆盖 Applied ML / MLOps / Generative AI / AI Platforms 等多场）
  - **The AI Platforms 系列**（对企业 AI 平台的评测与对比内容）
  - **TWIML Presents: AI in Financial Services**（行业细分版）

## 内容定位与形式

- **赛道**：机器学习 / 深度学习 / 数据科学 / MLOps / NLP / LLM / 企业 AI
- **形式**：单主持 + 1 嘉宾长访谈（**"researcher + practitioner" 兼顾**——嘉宾身份分布大致：30% 学术、40% 工业实践、30% 开源/初创）
- **更新频率**：**1-2 周一期**（长寿播客里相对高密度）
- **单集时长**：60-120 分钟
- **语言**：英文
- **风格**：
  - **采访深度**——Sam 的问题模板以"研究问题的方法论"著称，会追问"为什么选这个数据集""这个 baseline 为什么不公平"
  - **show notes 极详细**——包含论文链接 / 代码仓库 / 嘉宾所属公司主页，是"可执行信息"密度最高的英文 AI 播客之一
  - **"Long Now" 视角**——同一技术话题（如 RLHF、vector DB、prompt engineering）会在 5 年内反复邀请不同嘉宾回访，能看到"领域演化路径"

## 受众画像
