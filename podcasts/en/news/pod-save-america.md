# Pod Save America

## 简介

由奥巴马政府四位前幕僚(Favreau / Lovett / Pfeiffer / Vietor)主理的左翼政治播客,2017 年开播,被视为"特朗普时代"政治播客崛起的代表性节目,也是 Crooked Media 公司的旗舰节目。

## 主播与背景

- **Jon Favreau / Jon Lovett / Dan Pfeiffer / Tommy Vietor** —— 均为奥巴马政府核心幕僚,2017 年创立 Crooked Media,将自己定位为"民主党版的右翼电台阵营"(类比 *The Ben Shapiro Show* / *Pod Save America* 这种对位)。
- Crooked Media 2017 年起步,2022 年借 SiriusXM 合作扩张至 100+ 员工;2025-02 转投 Audioboom 自主运营。

## 内容定位与形式

- **赛道**:新闻 / 时政 / 评论(明确左翼立场)
- **形式**:四位主播圆桌对谈 + 时事评论 + 偶尔访谈政客
- **更新频率**:每周 2-3 期
- **单集时长**:60-90 分钟
- **语言**:英文

## 受众画像

民主党支持者、进步派、城市白领、25-55 岁政治参与度高的听众;节目也通过 MS NOW 合作扩展到线性电视频道(节目精简版)。

## 代表单集

- 美国大选周期特别篇(2018 / 2020 / 2022 / 2024)—— 节目中流量最稳定的内容主线。
- 重大政治事件(政府关门、最高法院裁决、Trump 二次执政)专题圆桌。

## 影响力与评测

- **Forbes 2026 收入榜 #9**:年入 **$28M**,四位主播按播客业务计税前收入。
- **Crooked Media 商业矩阵**:旗下多档节目同步分发,广告主覆盖范围广。
- **历史波动**:2024-2025 经历人员流失与裁员(行业普遍现象);2025-02 改投 Audioboom 是关键节点。
- **2026 行业意义**:与 *The Breakfast Club*(Charlamagne Tha God 主理,iHeart+Netflix 联合)对位,代表"主播主导媒体公司"模式的左右两极。
